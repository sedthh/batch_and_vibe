Talk to your creature

Type a message to your creature. This demo uses a dummy responder, so it repeats ordinary messages instead of answering them intelligently.

Commands for testing the demo
  • remember: be gentle with villagers — save a memory, replacing the previous memory.
  • memory — read the saved memory.
  • status — show the current simulated world information.
  • say: Hello! — display “Hello!” in the creature’s speech panel.
  • forget — clear the saved memory. Recent chat history is kept.
